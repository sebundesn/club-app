# LINE公式アカウント(リッチメニュー)導入手順

リッチメニューのボタンから既存のWebアプリを開く構成。LIFF SDK は使わず、
メニューのURLを LINE 内ブラウザで開き、既存の LINE ログインでそのまま入る。

## コストの前提(2026-10 時点の想定。契約前に公式の料金ページで確認すること)

- LINE公式アカウントは無料プラン(月200通までの push 送信)で足りる。
  このアプリは push 通知を使わず、確認はすべてメニューから Web を開く形にしているため。
- リッチメニュー、LINE ログインは無料。
- 追加の AWS 費用は S3 の保存料(写真・動画で月数十円〜)程度。

## 1. バックエンドを本番に出す前に(1回だけ)

1. `infra/` で `terraform plan` → 内容を確認 → `terraform apply`
   - 追加されるもの: メディア用S3バケット、CloudFront の `/media/*`、EC2のIAM権限、SSMの `MEDIA_BUCKET` / `AWS_REGION`
2. **EC2 に ffmpeg / ffprobe を入れる**。AL2023 の標準リポジトリには `ffmpeg-free` が無い
   (2026-10 に確認済み: `dnf install ffmpeg-free` は "No match")ので、静的ビルドの arm64 版を
   `/usr/local/bin` に置く。取得元とチェックサムを確認してから入れること。
   入れたら `ffmpeg -version` と `ffprobe -version` で確認する。
3. バックエンドをデプロイ(通常のCI)。起動時に新しいテーブル・列が自動で作られる。
4. **動作確認(t4g.micro で動画変換が実用か)**: 1分の動画を実機から上げて、完了までの時間を測る。
   遅い・本体が重くなる場合は `infra/variables.tf` の `instance_type` を `t4g.small` に上げる。

## 2. 既存のレシート画像について

- 旧データ(サーバーの `uploads/`)はそのまま表示できる。S3 への移行は不要。
- 新しくアップロードした分から S3 に入り、15分有効の署名付きURLで表示される。

## 3. LINE 側

1. LINE Developers で、既存の LINE ログインのチャネルと同じプロバイダーに **Messaging API チャネル**を作る
   (LINE公式アカウントマネージャーで公式アカウントを作ると自動で作られる)。
2. 公式アカウントの「応答設定」で、あいさつメッセージ・応答メッセージをオフにする(無料枠を消費しないため)。
3. メニュー画像(2500x843px、左から「予定表」「部費」「アルバム」「アップロード」の4分割)を用意する。
   マネージャーのテンプレートは、横に4つ並ぶものを選ぶ。
   各ボタンのリンク先は次のとおり。**すべて外部ブラウザで開く**(`openExternalBrowser=1`)。
   LINE内ブラウザでは、初回ログインの認証番号をLINEアプリで確認できず、ログイン状態も
   外部ブラウザと共有されないため。外部ブラウザなら、認証番号をLINEアプリで見て入力できる。
   - 予定表: `https://<サイトのURL>/calendar?openExternalBrowser=1`
   - 部費: `https://<サイトのURL>/payments?openExternalBrowser=1`
   - アルバム: `https://<サイトのURL>/album?openExternalBrowser=1`
   - アップロード: `https://<サイトのURL>/upload?openExternalBrowser=1`
4. 登録:
   ```bash
   LINE_CHANNEL_ACCESS_TOKEN=... SITE_URL=https://xxxx.cloudfront.net \
     ./scripts/richmenu/create.sh menu.png
   ```
5. 友だち追加用のQRを部員に配る。

## 運用メモ

- ログインは「最後に開いてから90日」保たれる(開くたびに延長される)。90日開かなければ、もう一度LINEログインが必要。
- 部員は、初回だけ外部ブラウザでLINEログイン(認証番号)が必要。ブラウザを変えると、そのブラウザで再ログインが必要。

- アップロードページ(`/upload`)で、イベント(初期は今日から1週間前まで。前後は1週間ずつ切り替え)を選んで、写真・動画・レシートを追加できる。レシートは部員全員が出せて、見られるのは会計・部長・副部長だけ。
- 写真は1イベント150枚、動画は10本(各60秒以内)まで。上限に達したら削除すると枠が空く。
- 「1人あたりの枚数上限」は未実装(必要なら `event_media.uploader_id` で数えられる)。
- 未払いは本人の分だけ表示される。全員分を見られるのは会計・部長・副部長。
- 徴収額の設定と支払い済みの切り替えは、会計・部長が、会計ページのイベントの「参加者」欄で行う。
